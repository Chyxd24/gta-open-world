An original, fully playable **open-world crime sandbox** for the desktop browser, built with
Three.js and pure procedural content — no external assets, no network requests, no build step.
Every street, building, neon sign, vehicle, pedestrian and sound is generated by the game's own
code at load time.

> **Play:** open `game/index.html` in desktop Chrome. That's it — no install, no server.

Neon City is an entry in the [make.fun **Make GTA 6** bounty](https://make.fun/bounty/gta6-01)
($1,666 total prize pool). It is **100% original** — its city, characters, vehicles, story,
names, art and synthesized audio share nothing with any commercial game.

---

## The game

You play a small-time hustler on the Neon Strip who goes to work for **Rook** and crosses paths
with the crew boss **Sable Vex**. Four story missions take you across the city's four districts —
from a cold-start car theft through a police ambush to a final showdown in the plaza.

### Features

- **A living city to explore on foot and by car.** A procedurally-built grid of 4 named districts
  (Neon Strip, Harbor Row, Old Verde, Glass Heights) with distinct palettes, block heights and
  neon signage. Traffic drives the road network and pedestrians wander the sidewalks.
- **Steal any car.** Walk up to traffic or a police cruiser and press **E** to jack it. Arcade
  driving model with acceleration, braking, handbrake, body roll and crash sparks.
- **Wanted level + police response.** Crimes raise a 5-star wanted meter. Cruisers with strobing
  light bars and wailing sirens pursue and block you; foot officers deploy from stopped cars,
  strafe and shoot back. Heat decays once you break line of sight.
- **Combat.** Four weapons — fists, Sidearm 9, Vector SMG, Breacher 12 — with reloads, ammo,
  weapon swapping, and tracer/blood/spark effects.
- **Missions with a story.** Objective markers, briefing toasts, a mission-passed screen and a
  finale. Progression pays out cash rewards.
- **HUD with a live minimap.** The minimap draws the street grid, traffic, pedestrians, police and
  the current objective marker in real time. Health, armor, cash, wanted stars and weapon/ammo
  are always on screen.
- **Start screen, pause menu, and saving.** The game auto-saves to `localStorage` on pause and
  mission completion; continue a run where you left off.
- **Procedural audio.** A synthwave backing loop, engine drone, two-tone police siren, gunshots,
  impacts and UI stings — all generated live with WebAudio, no sound files.
- **Polished feel.** Mouse-orbit third-person camera with building occlusion pull-in, smooth
  follow, shadows, fog, and a full menu flow (start → play → pause → death → mission passed).

## Running it

Open `game/index.html` in desktop Chrome (or any modern browser). The game is a set of static
files — it needs no build step and makes no network requests. Everything, including the vendored
Three.js engine (`game/vendor/three.min.js`), is bundled in the repo.

`main.ts` (Node 22) is the entry program: it copies `game/` and `screenshots/` to the output
directory and writes `dossier.json` with the kit's `buildDossier` library.

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

## Project layout

```
game/
  index.html          page, menus and script load order
  src/
    config.js         tuning constants, district + city layout, math helpers
    world.js          procedural city geometry, road network, collision
    vehicles.js       car meshes, arcade physics, traffic AI
    characters.js     humanoid meshes, pedestrians
    player.js         on-foot + driving controller, camera, shooting
    wanted.js         crime tracking, star rating, heat decay
    police.js         cruisers, foot officers, pursuit + combat AI
    missions.js       story missions, objectives, markers
    fx.js             tracers, sparks, blood, smoke, explosions, floating text
    hud.js            DOM HUD + live minimap
    audio.js          procedural WebAudio engine / siren / music
    save.js           localStorage persistence
    shots.js          headless screenshot staging helper
    game.js           boot + main loop orchestrator
    style.css         HUD + menu styling
  vendor/
    three.min.js      Three.js r160 (vendored, minified)
screenshots/          4 real renders of the running game
main.ts               entry program (copies game + screenshots, writes dossier.json)
vendor/makefun-game.ts  kit's dossier library (unchanged)
```
